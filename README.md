# To Do list Manager

The To Do list Manager is built to create, update and manage tasks, from the app user interface.

## Steps to Run
1. Download project
2. Open Terminal and navigate to project path
3. Type command
   ```
   python app.py runserver
   ```
4. The CMD with give a URL, copy and paste it in browser to open app. <br/>
   For example:
   ```
    Running on http://127.0.0.1:5000
   ```
